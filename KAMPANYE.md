# Ekspansi mode kampanye

Buka [`kampanye.html`](kampanye.html) di browser atau di situs GitHub Pages. Halaman ini berbagi simpanan `localStorage` dengan `index.html`, jadi emas, makanan, pengaruh, tahun, dan pekan menggunakan dunia yang sama.

Fitur mode kampanye: rekrut dan latih rombongan, kontrak pengawalan, patroli jalur, ekspedisi dengan hasil berbasis kekuatan rombongan, pengajuan piagam wilayah, kemasyhuran, semangat, serta pemasukan wilayah. Pertempuran diselesaikan secara abstrak dengan statistik dan kejadian naratif agar ringan dan cocok untuk game teks.

## Catatan

Ini adalah sistem orisinal bertema kampanye dan pengelolaan rombongan. Tidak ada kode, aset, faksi, atau teks dari Mount & Blade II: Bannerlord yang digunakan.
